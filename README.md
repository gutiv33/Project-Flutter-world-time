# flutter_time


* dependencies: ->   #การเพิ่ม Package (แพ็กเกจ / ไลบรารี) ของ Dart & Flutter ที่ช่วยให้เรา เรียกใช้งาน HTTP / API / Web service ได้ง่ายขึ้น
  จะมีการเขียนในรูปแบบนี้
            flutter:
            sdk: flutter
            http: ^1.6.0                -> #ดึงข้อมูลจากเว็บ (Rect API)
            intl: ^0.20.2               -> #ตัวจัดการ format ของข้อมูล (วัน เวลา เเละตัวเลข)
            flutter_spinkit: ^5.2.2     -> # การทำหน้าตัว load ข้อมูลขึ้นมาเป็นหัวใจ (loading animation)
            lottie: ^3.3.2              -> #การทำแอนิเมชัน (แสดงแอนิเมชันจากไฟล์ .json (Lottie))
            flutter_map: ^8.2.2         -> #เกี่ยวกับแผนที่
            latlong2: ^0.9.1            -> #เกี่ยวกับแผนที่ พวกตำแหน่ง
            flutter_speed_dial: ^7.0.0  -> #ทำให้ตัวปุ่มลอยได้
            geolocator: ^14.0.2         -> #เข้าถึงตำเเหน่ง (GPS)

  
* ใช้ timeapi.io  เพื่อที่จะดึงเวลาออกมา
* ใช้ openstreetmap เพื่อที่จะใช้ตัว map
